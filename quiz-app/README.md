# آزمون آنلاین | Quiz App

وب اپلیکیشن کوئیز فارسی با طراحی زیبا و کاربرپسند که با Next.js، React، TypeScript، Tailwind CSS، Zod و Zustand ساخته شده است.

## ویژگی‌های برجسته

### 🎯 عملکرد
- **۶ دسته‌بندی مختلف**: هوش، اطلاعات عمومی، زبان انگلیسی، تاریخ، علوم، ادبیات
- **۷ سوال تصادفی** برای هر آزمون از مجموعه ۱۰ سوال
- **زمان‌سنج ۷ دقیقه‌ای** با نمایش بصری و هشدارهای رنگی
- **نوار پیشرفت** برای نمایش وضعیت آزمون
- **نتایج کامل** شامل نمره، تعداد پاسخ‌های درست/غلط، زمان صرف شده

### 🎨 طراحی و رابط کاربری
- **تم تاریک** با گرادیان‌های زیبا
- **فونت Vazirmatn** برای بهترین نمایش متن فارسی
- **انیمیشن‌های روان** و افکت‌های hover
- **طراحی واکنش‌گرا** (Responsive) برای همه دستگاه‌ها
- **کارت‌های دسته‌بندی** با رنگ‌های منحصر به فرد
- **نمایش دایره‌ای نمره** در صفحه نتایج

### ⚡ تکنولوژی‌ها
- **Next.js 15** - فریمورک React
- **TypeScript** - برای امنیت تایپ
- **Tailwind CSS** - برای استایل‌دهی
- **Zustand** - مدیریت state
- **Zod** - اعتبارسنجی داده‌ها
- **React Hooks** - مدیریت lifecycle

## نحوه اجرا

### پیش‌نیازها
- Node.js 18+ 
- npm یا yarn

### نصب و راه‌اندازی

```bash
# کلون کردن پروژه
git clone <repository-url>
cd quiz-app

# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه
npm run dev

# ساخت برای production
npm run build

# اجرای نسخه production
npm start
```

پس از اجرا، وب‌سایت روی آدرس `http://localhost:3000` در دسترس خواهد بود.

```
quiz-app/
├── src/
│   ├── app/                 # Next.js App Router

│   │   └── page.tsx         # صفحه اصلی

│   │   ├── QuestionCard.tsx # کارت سوال
│   │   ├── QuizResult.tsx   # نمایش نتایج
│   │   └── Timer.tsx        # زمان‌سنج
│   ├── data/
│   │   └── quizData.ts      # داده‌های سوالات
│   ├── store/
│   │   └── quizStore.ts     # Zustand store
│   ├── types/
│   │   └── quiz.ts          # تایپ‌های TypeScript
│   └── utils/
│       └── helpers.ts       # توابع کمکی
├── tailwind.config.ts       # تنظیمات Tailwind
└── package.json
```

## نحوه استفاده

1. **انتخاب دسته‌بندی**: روی یکی از ۶ کارت دسته‌بندی کلیک کنید
2. **پاسخ دادن**: گزینه مورد نظر را انتخاب کنید
3. **حرکت بین سوالات**: با دکمه "سوال بعدی" ادامه دهید
4. **مشاهده نتایج**: پس از پاسخ به همه سوالات، نتایج نمایش داده می‌شود
5. **شروع مجدد**: با دکمه "آزمون جدید" دوباره شروع کنید
